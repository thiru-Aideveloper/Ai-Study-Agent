# 🤖 AI Study Agent

An AI-powered study assistant built using **Python and Streamlit** to help students organize their learning, practice concepts, and track their study progress.

## 📌 About the Project

AI Study Agent is a simple and user-friendly web application designed for students.

It provides different study tools in one place, making daily learning easier and more organized.

## ✨ Features

- 📚 **Study Planner** – Create a simple study plan based on subject, study hours, and difficulty.
- 🧠 **AI Tutor** – Get basic explanations for study-related questions.
- ❓ **Quiz** – Test your Python knowledge with interactive questions.
- 📊 **Progress Tracker** – Monitor your study completion percentage.
- 📄 **Notes Analyzer** – Upload text notes and view basic note statistics.

## 🛠️ Technologies Used

- 🐍 Python
- 🎨 Streamlit
- 💻 PyCharm
- 📦 Base Python Libraries
